\# Pixora – AI Hand Gesture Recognition



Pixora is a real-time hand gesture recognition web application built using Python, Flask, OpenCV, and MediaPipe.



\## Features



\- Real-time hand tracking using a webcam

\- Detection of one or two hands

\- Finger counting (up to 10 fingers)

\- Hand gesture recognition

\- Live camera feed through a web interface

\- Interactive dashboard



\## Tech Stack



\- Python

\- Flask

\- OpenCV

\- MediaPipe

\- HTML

\- CSS

\- JavaScript



\## Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/nishtha26-ai/Pixora.git

&#x20;  ```



2\. Navigate into the project:



&#x20;  ```bash

&#x20;  cd Pixora

&#x20;  ```



3\. Create and activate a virtual environment:



&#x20;  ```powershell

&#x20;  py -3.12 -m venv .venv

&#x20;  .\\.venv\\Scripts\\Activate.ps1

&#x20;  ```



4\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



5\. Run the application:



&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```



6\. Open the local URL displayed in your terminal.



\## Note



Pixora requires webcam access. Gesture recognition performance may vary depending on lighting and camera quality.
